# Sales-performance-dashboard
Excel sales analysis and dashboard project

## Project Overview

This project demonstrates sales data cleaning, validation, analysis, and dashboard creation using Microsoft Excel.

The dataset contains 100 sales orders and was analyzed to identify sales performance across products, regions, and categories.

## Data Cleaning & Validation

- Checked the dataset for missing values and inconsistencies
- Corrected inconsistent product, category, and region names
- Filled a missing quantity value
- Checked for duplicate Order IDs
- Validated revenue calculations

## Analysis

Created Pivot Tables to analyze:

- Revenue and quantity by product
- Revenue by region
- Revenue by category

## Dashboard

The dashboard includes:

- Total Revenue: 123,304.80
- Total Orders: 100
- Units Sold: 447
- Average Order Value: 1,233.05
- Revenue by Product
- Revenue by Region
- Revenue by Category
